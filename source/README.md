# 남선우 포트폴리오 — 복구한 편집용 소스

기존 Railway 사이트는 컴파일된 정적 결과물만 남아 있었으므로, 공개된 콘텐츠와 기존 미디어 자산을 바탕으로 React/Vite 소스를 새로 작성했습니다. 원본 소스의 정확한 복원은 아니며, 디자인과 인터랙션은 재구현한 것입니다.

## 로컬 실행

```bash
npm install
npm run dev
```

## 배포 전 확인

```bash
npm run build
npm run preview
```

`src/projects.js`에서 작품 설명과 영상/이미지를 관리합니다. `public/`에는 기존 저장소에 들어 있던 미디어 파일을 복사했습니다. Railway 운영 프로젝트는 아직 이 소스로 변경되지 않았습니다. 검증 후 배포 설정의 루트 디렉터리를 `/source`로 지정하거나, 별도 브랜치/프리뷰 배포를 사용하세요.
